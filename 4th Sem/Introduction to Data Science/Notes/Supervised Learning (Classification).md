- The training data are accompanied by labels, indicating the class of observations 
- New data is classified based on the training set
- It solves predictive Problems 

- **Classification**: 
	- predicts categorical class labels (discrete or nominal) 
	- classifies data based on the training set and values (class labels) in a classifying attribute and uses it in classifying new data 
- **Numeric prediction**:
	- models continuous valued functions, i.e., predicts unknown or missing values - Regression. 

**Two Step Process**: 
1. Model Construction:
	- Each tuple/sample is assumed to belong to a predefined class 
	- the set of tuples used for model construction is training set 
	- The model is represented as classification rules, decision trees, or mathematical formulae. 
2. Model Usage: 
	- Estimate accuracy of model 
	- If accuracy is acceptable, use model to classify new data
